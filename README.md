# 宝箱をさがせ（佐渡旅代替交流会の謎解きサイト）

佐渡島マップの見た目をコピーして、謎解き用に独立させたサイトです。元の佐渡島マップ（sado_map）とは、コードもデータも共有していません。サーバーやデータベースは使わず、GitHub Pages だけで動きます。

公開URL：https://rec-rodorigues.github.io/sado-nazotoki/

## できること

- **チームを選ぶ**：チームで1台の端末を使う。進み具合はその端末のブラウザに保存される。
- **書類**：第一幕から順に書類が届く。正解した書類には「正解」の印がつく。
- **回答（Bot）**：書類の番号を選んで答えを送ると、正解か判定する。正解すると地図にトキの点が2〜3個増え、条件を満たすと次の書類が届く。カタカナ・ひらがな、全角・半角の違いは区別しない。
- **地図**：60点そろうと点が線でつながり、トキの絵になる。「地点追加」は合言葉が正しいときだけ登録でき、くちばしの先（佐渡金山）から1.5km以内に登録すると宝箱が見つかる。

## 答えが見えないしくみ

`data.js` には答えのハッシュしか入っていません。正解すると、打った答えを鍵にして、トキの点の座標・次の書類ページの名前・宝箱の場所を解読します。ソースを見ても、まだ解いていない部分はわかりません。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面とデザイン |
| `app.js` | 画面の動き |
| `api.js` | 答えの判定と進み具合の保存 |
| `data.js` | 問題・答えのハッシュ・暗号化した点の座標など（作成スクリプトで作る） |
| `p/` | 書類のページ（推測しにくい名前） |

## 運営メモ

- 本番前に試した端末は、右上のチーム名を押してチーム選択に戻り、「このチームの進み具合を消す」で消しておく。
- プライベートモード（シークレットウィンドウ）では、閉じると進み具合が消える。
- 問題や答えを直すときは、`data.js` と `p/` を作り直す（元の謎のページから自動で作っている）。
